## 🚀 Instant Deployment to Vercel

This repository is pre-configured with full **Vercel** support (`vercel.json`, `index.html`, clean URLs, and routing).

### Method 1: Deploy with Vercel CLI (Fastest)
Open your terminal inside this folder and run:
```bash
npx vercel
```
- When prompted:
  - **Set up and deploy?** Press `y`
  - **Which scope?** Choose your Vercel account
  - **Link to existing project?** Press `n`
  - **What's your project's name?** Enter `smart-shopping-mall-network`
  - **In which directory is your code located?** Press `Enter` (current `./`)
  - **Want to modify these settings?** Press `n`
- Your live public URL will be generated instantly (e.g. `https://smart-shopping-mall-network.vercel.app`)!

To deploy directly to production:
```bash
npx vercel --prod
```

### Method 2: Deploy via GitHub (Recommended for Collaboration)
1. Go to [vercel.com/new](https://vercel.com/new).
2. Import this GitHub repository (`computer-network-`).
3. Click **Deploy**.
