02 Problem & objectives

Why modern malls require structured networking

Commercial malls combine high-risk financial payment terminals, CCTV streams, and open public Wi-Fi on a shared physical facility. Zero Trust Segmentation is mandatory.

Operational Challenges

When a shopping mall runs on a flat unmanaged network, broadcast storms degrade performance, camera video chokes retail POS bandwidth, and card terminals become vulnerable to packet sniffing.

Core Architectural Goals

  • Strict segmentation: Isolate stores, POS, surveillance, parking, and guest Wi-Fi.
  • PCI-DSS compliance: Shield card billing registers from guest intrusion.
  • Automated configuration: Zero-touch DHCP dynamic scopes across subnets.
  • Wire-speed routing: Cisco 3560 Multilayer switching for line-rate forwarding.
  • Perimeter control: Hardware Extended ACLs enforcing strict traffic policies.

05 Core routing & SVIs

Hardware-based inter-VLAN routing via Cisco 3560

Instead of sending departmental packets through an external router bottleneck, the Cisco Catalyst 3560 Multilayer Switch routes traffic at line-rate using Switched Virtual Interfaces (SVIs).

Why SVIs Beat Router-on-a-Stick

  • No link saturation: Eliminates the single trunk interface bottleneck.
  • ASIC hardware speeds: Packets forward at multi-gigabit wire speed.
  • Lower latency: Crucial for real-time POS EMV transactions and NVR camera feeds.
CORE-SW · SVI Configuration

Project 7: Smart Shopping Mall Network05 / 10
A common student design flaw is relying on router-on-a-stick, which creates a huge bottleneck on the single router uplink. In our design, we enabled 'ip routing' directly on the Cisco 3560 Core Switch. By configuring Switched Virtual Interfaces—or SVIs—for each VLAN, the core switch acts as the local gateway. Packets between the retail stores and the central server are routed inside the switch at gigabit speeds without ever leaving the switch chassis.

07 Network security & ACLs

Zero trust security & payment terminal isolation (PCI-DSS)

VLANs create boundaries, but Access Control Lists (ACLs) enforce security. Customers on public Wi-Fi can browse the internet and web portal, but are strictly blocked from POS and CCTV.

Security Enforcement Code

CORE-SW · Extended ACL 100
! Block customer access to payment card terminals
access-list 100 deny ip 10.10.70.0 0.0.0.255 10.10.30.0 0.0.0.255

! Block customer access to security camera streams
access-list 100 deny ip 10.10.70.0 0.0.0.255 10.10.50.0 0.0.0.255

! Allow legitimate outbound web & internet traffic
access-list 100 permit ip any any

! Apply filter directly to Wi-Fi Gateway
interface Vlan 70
 ip access-group 100 in
PCI-DSS 1.3 Compliance: Prohibits direct access between the Internet or guest Wi-Fi and the cardholder data environment (POS VLAN 30).
Project 7: Smart Shopping Mall Network07 / 10
Security is where many projects fail evaluation. VLANs separate broadcast traffic, but by default a router routes between all connected VLANs. Without ACLs, a customer on guest Wi-Fi could reach a POS terminal. We wrote Extended Access Control List 100 and applied it to incoming traffic on VLAN 70. It explicitly denies any packet destined for the POS or CCTV subnets, while allowing traffic out to the web server and internet. In Packet Tracer, testing a ping from the laptop to the POS terminal returns 'Destination host unreachable'.
08 Wireless & smart parking

Integrated guest Wi-Fi & smart parking IoT architecture

Guest Wi-Fi Architecture (VLAN 70)

The Wireless client connects through an Access Port on SW3-PARKING-WIFI assigned to VLAN 70. Any associated device is automatically quarantined in the isolated guest domain.

Air-Gap Isolation: Public guests cannot discover internal switches or access management subnets.

Smart Parking IoT Integration (VLAN 60)

The parking facility uses automated boom barriers and ultrasonic sensors reporting vehicle counts to the central database.

  • Dedicated IoT Subnet: 10.10.60.0/24 isolates telemetry from public traffic.
  • Low Latency Processing: Fast barrier gate scans routed locally on the Core 3560.
  • Port Security: Restricts physical switch interfaces against rogue taps in parking bays.

10 Conclusion & roadmap

Engineering summary & future enhancements

Key Architectural Achievements

The Smart Shopping Mall Network successfully translates fundamental computer networking principles into an enterprise-ready commercial design:

  • Eliminated Broadcast Storms: Segmented 8 distinct operational departments.
  • High-Throughput Backbone: Cisco 3560 Core switch routes traffic at wire speed.
  • PCI-DSS Aligned Security: Complete logical isolation of card payment endpoints.
  • Modular Scalability: New retail blocks or kiosks attach without network redesign.
  • Centralized Administration: Unified DHCP pools and local DNS name resolution.
Deliverables: Complete working .pkt simulation file, verified CLI configurations, and oral defense viva notes.

Future Roadmap

  • HSRP / VRRP: Dual-core switch redundancy for 99.999% high availability.
  • 802.1X Authentication: Port-level identity checks for tenant devices.
  • Dynamic AI QoS: Traffic prioritization for POS during peak holiday shopping hours.
  • Dual-WAN Failover: Secondary ISP uplink with automated failover routing.
